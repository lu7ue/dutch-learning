## 1. 动词基础：现在时（规则动词）

- 大多数荷兰语动词以 **-en** 结尾（如：werken, maken, reizen）
- 现在时多数为规则变化

---

### 1.1 动词变位步骤

步骤：

1. 从原形（infinitive）开始，去掉 **-en** → 得到词干（stem）  
2. 根据词干调整拼写：  
a）如果元音应为长音 + 后面有辅音 → 双写元音  
b）如果结尾有两个相同辅音 → 去掉一个  
c）词尾 **z → s**  
d）词尾 **v → f**

---

### 1.2 现在时变位规则

| 人称 | 形式 |
|------|------|
| ik | stem |
| je/jij, u | stem + t |
| hij/zij/het | stem + t |
| we/wij | 原形 |
| jullie | 原形 |
| ze/zij | 原形 |

词干已以 **t 结尾** → 不再加 t ；  
词干以 **d 结尾**（发音为 t）→ 仍加 t（拼写为 dt）。

---

### 1.3 示例

| 原形 | stem | ik | jij | hij | wij |
|------|------|----|-----|-----|-----|
| bakken | bak | bak | bakt | bakt | bakken |
| werken | werk | werk | werkt | werkt | werken |
| maken | maak | maak | maakt | maakt | maken |
| reizen | reis | reis | reist | reist | reizen |
| verven | verf | verf | verft | verft | verven |

---

### 1.4 倒装时的特殊规则

当 **je/jij 在动词后**：

- 去掉 -t

例：
- werk je（不是 werkt je）
- maak je

注意：
- **u 不受影响** → werkt u（保留 t）

## 2. 不规则动词（现在时）

### 2.1 zijn（是）和 hebben（有）

#### zijn

| 人称 | 形式 |
|------|------|
| ik | ben |
| jij | bent |
| hij/zij/het | is |
| wij | zijn |
| jullie | zijn |
| zij | zijn |

#### hebben

| 人称 | 形式 |
|------|------|
| ik | heb |
| jij | hebt |
| u | hebt / heeft |
| hij/zij/het | heeft |
| wij | hebben |
| jullie | hebben |
| zij | hebben |

---

### 2.2 不规则动词类型：-n 结尾

步骤：

1）原形  
2）去掉 **-n**  
3）得到词干

例：

| 原形 | stem |
|------|------|
| gaan | ga |
| slaan | sla |
| staan | sta |
| doen | doe |
| zien | zie |

变位规则和规则动词一样：

| 动词 | ik | jij | hij | wij |
|------|----|-----|-----|-----|
| gaan | ga | gaat | gaat | gaan |
| slaan | sla | slaat | slaat | slaan |
| staan | sta | staat | staat | staan |
| doen | doe | doet | doet | doen |
| zien | zie | ziet | ziet | zien |

## 3. 情态动词（modal verbs）

包括：

- kunnen（能）
- zullen（将要）
- mogen（可以/允许）
- willen（想要）

特点：
- 现在时只有两种形式：单数 / 复数

moeten（必须）是规则动词！

---

### 3.1 变位表

| 人称 | kunnen | zullen | mogen | willen |
|------|--------|--------|--------|--------|
| ik | kan | zal | mag | wil |
| jij | kan （书面 kunt） | zal （书面 zult） | mag | wil （书面 wilt） |
| hij | kan | zal | mag | wil |
| wij | kunnen | zullen | mogen | willen |
| jullie | kunnen | zullen | mogen | willen |
| zij | kunnen | zullen | mogen | willen |

---

### 3.2 句子结构

规则：

1）后面接动词原形  
2）**不加 te**  
3）原形放句尾

例：

Ik kan goed zwemmen - I can swim well  
Ik zal je morgen bellen - I will phone you tomorrow  
Ik wil dit boek lezen - I want to read this book
